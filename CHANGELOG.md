# Changelog

All notable changes to SafeTalk are documented here.

## [Released]

### Added

- Email OTP authentication and account signup.
- Admin user management and an idempotent test-account seed script.
- Real-time direct and group messaging, presence, typing indicators, and file uploads.
- SafeTalk favicon, page metadata, and a robots file.
- Project setup, configuration, and contribution documentation.
- Sidebar logout control.

### Fixed

- Client styling and missing frontend API exports.
- Authentication response and authorization data needed for admin access.
- Redis configuration loading during server startup.
- Chat scrolling to the latest messages and loading older messages while preserving scroll position.
